# План реализации — Обновление кнопки «Назад» в меню домика

Этот план описывает замену текстовой кнопки «Назад» (Cancel) в деталях домика на современную круглую кнопку с иконкой стрелки, адаптированную для мобильных устройств и планшетов.

## Требуется обзор пользователя

> [!NOTE]
> - Вместо текстовой кнопки `< Отмена` будет использоваться круглая кнопка `IconButton` с иконкой `ArrowBack`.
> - Кнопка будет иметь легкий фоновый круг для лучшей видимости, выдержанный в фирменном зеленом цвете приложения (`0xFF1B4332`).

## План верификации

### Ручная проверка
1. Открыть любой домик.
2. Убедиться, что в верхнем левом углу отображается круглая кнопка со стрелкой.
3. Проверить, что нажатие на кнопку возвращает к списку домиков.
4. Проверить отображение на телефоне и планшете (в горизонтальной и вертикальной ориентации).

- Сборка проекта через `./gradlew assembleDebug`.
